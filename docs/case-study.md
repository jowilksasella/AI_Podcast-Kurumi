# GEX 制作中保留下来的方法

这套流程来自一次把研究白皮书做成普通话角色闲聊的实践。

以下保留早期制作记录。v0.1.0 是此次从原始 commit `e23d5bf` 补标的完整原版快照，不表示此前已发布过 v0.1.0；旧 `main` 保持不变。v0.2.0 是独立的连续模式尝试，早期“短句分段”不再是其默认推理策略。
原版可直接克隆 `v0.1.0` 或在 GitHub Tags 下载，无需 revert 或 cherry-pick；版本入口见 [README](../README.md)。[v0.2.0 经验](continuity-v0.2.0.md) 中的 5.91 秒认可只限短样个案，后续双人音频与两位声优轻状态校准未获认可，不能当作整体声线优化保证；完整结果见 [发布说明](release-notes-v0.2.0.md)。

1. 单句独立朗读 + 固定停顿，容易像轮流念稿。先改成朋友间发现一个有趣现象，再调整接话节奏。
2. 不直接生成全篇。30–60 秒能先发现声音、信息密度、角色分工的问题，减少整集返工。
3. 久留美必须真正讲主要知识。最终按台词量和发言时间确认主讲，而不是只数说了几轮。
4. 本地 IndexTTS 2.5 可以把日语公开参考样本用于普通话生成，音色与情绪参考分开配置。
5. 声优公开样本、其他角色模型、目标角色专用模型不是同一件事；既不能拿绘图 LoRA 当声音，也不能拿其他“Kurumi”当福贺久留美。
6. 早期对长段解码重复采用自然短句分段与按段缓存。v0.2.0 将其保留为显式 `legacy_chunks`；默认改为完整短 turn 的 continuous 调用，容量超限时先重写自然角色 exchange。
7. 跨语言发音可能让单字“买/卖”混淆。先把动作写明确，再只修问题处；没有必要全局加入发音标签。
8. 完整版也需要开场。短样的冷开场不能直接当成完整节目的第一秒；新增铺垫时要检查与旧第一句的衔接。
9. 修改开场只生成头部，保留原正文母带，字幕和章节统一顺延。
10. 研究结果与比喻分开：历史样本、模型假设、单位、波动与方向不能混写。

本仓库没有上传这次的原 PDF、原声音、模型权重或成片。
