# GEX 制作中保留下来的方法

这套流程来自一次把研究白皮书做成普通话角色闲聊的实践。

1. 单句独立朗读 + 固定停顿，容易像轮流念稿。先改成朋友间发现一个有趣现象，再调整接话节奏。
2. 不直接生成全篇。30–60 秒能先发现声音、信息密度、角色分工的问题，减少整集返工。
3. 久留美必须真正讲主要知识。最终按台词量和发言时间确认主讲，而不是只数说了几轮。
4. 本地 IndexTTS 2.5 可以把日语公开参考样本用于普通话生成，音色与情绪参考分开配置。
5. 声优公开样本、其他角色模型、目标角色专用模型不是同一件事；既不能拿绘图 LoRA 当声音，也不能拿其他“Kurumi”当福贺久留美。
6. 长段落偶尔解码重复。自然短句分段与按段缓存，比盲目整集重试可靠。
7. 跨语言发音可能让单字“买/卖”混淆。先把动作写明确，再只修问题处；没有必要全局加入发音标签。
8. 完整版也需要开场。短样的冷开场不能直接当成完整节目的第一秒；新增铺垫时要检查与旧第一句的衔接。
9. 修改开场只生成头部，保留原正文母带，字幕和章节统一顺延。
10. 研究结果与比喻分开：历史样本、模型假设、单位、波动与方向不能混写。

10 月 2 日的成功声音还依赖实际中文情绪参考，不仅是模型版本和演员样本。历史模板没有包含这些输入；恢复入口、空映射根因和试听/开场/正文的区别见[恢复与迁移](original-chat-restoration.md)。写作示例以 [preview.json](../examples/preview.json) 为唯一规范版本，新渲染仍需试听认可。
