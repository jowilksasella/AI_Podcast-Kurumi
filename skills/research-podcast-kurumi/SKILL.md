# 久留美主讲研究播客 · v0.2.0

收到本仓库链接时，把它当作制作方法入口，不要只介绍工具。读取当前资料与本机环境后推进对应阶段。

## 固定选择

- 默认久留美主讲、萌智子搭档；可按用户明确选择加入芽吹、やす子。不能把久留美降成只提问的配角。
- 完整剧本主讲台词量目标 65–75%，成片有效发言至少 60%。搭档承担部分知识、接话和校对。
- 实际音频用普通话，文字稿默认简体中文。用户的粤语指令可以保留其语气，但不要擅自把成片改为粤语。
- 使用已确认的本地声线与引擎，优先已有 IndexTTS 2.5；不自动切换 Edge。
- 优先用户试听确认的平稳原声；真人/声优样本与真实角色对白分开标注，参考合成不称为角色专用模型或本人对白。
- 默认连续模式：保持同一角色 turn 的完整短段，不逐句重启，不将整集多角色文本塞成一次调用。容量边界与显式参数以 [runtime.md](references/runtime.md) 为准。

## 阶段与完成标准

### 1. 取材与角色

遵循宿主的 research-first 要求。查原文、模型官方文档和 GitHub 可复用实现，再实施。
读取 PDF 的正文与关键图表，记录页码、研究年代、单位、假设、结果和解释边界。
角色、声优、参考音频的对应需要实际来源，不拿同名其他角色或绘图 LoRA 当声音模型。

完成标准：资料可追溯；主讲及搭档确定；现有模型路径和真实参考音频可用。缺资料/素材时报告具体缺项，不制造内容或假声音。

### 2. 写短样

首次写作或更换声线前，读 [writing.md](references/writing.md)。仅校准声线或排查语气时进入阶段 3 的短校准分支；正式节目样片仍按本阶段写作。
写 30–60 秒短样，包含一两句人物/话题铺垫、一个有趣现象、一次知识解释、自然接话。
把主讲角色的理解表现出来，避免拍档讲完、久留美只说“原来如此”。

完成标准：听众知道谁在聊、聊什么；样片体现真实信息密度和角色分工，不是只读一个欢迎语。

### 3. 声线和短试听

要执行音频命令时，读 [runtime.md](references/runtime.md)。
复用现有模型环境；speaker 和默认 emotion 沿用同一份已确认原声。独立 emotion_audio 只在用户明确需要时配置，delivery 标签本身不触发强情绪。
声线或跨句跳层排查时，先读 [continuity.md](references/continuity.md)。校准可单独生成约 5–15 秒，直接交付 native 短样，不为满足正式预览时长凑稿。
正式节目则先校验计划，生成 30–60 秒样片。检查实际时长、语言、参考身份、关键词与片段完整性。用户试听确认音色；ASR 仅辅助文字检查，SNR、无 clipping 和文件成功不能证明声线匹配。没有直接音频听辨能力时，不声称自己听过。
给用户可直接播放的本地音频或可用预览，停在短样，不自行扩成整集。

完成标准：校准分支交付可播放短样并记录用户声线反馈；正式样片分支交付真正生成的 30–60 秒样片。身份、调用方式和证据范围标注准确；校准认可不自动批准完整版。

### 4. 完整版

仅在用户明确认可短样并要求开始后推进。根据原文写完整剧本，保持已确认的声音、口语感和主讲结构。
校验主讲比例、铺垫、资料覆盖与来源。把长解释写成自然角色 exchange，每个短 turn 保持完整上下文，按 turn 缓存和恢复。
continuous 超出低显存或 token 容量时明确失败；重写对话或由用户显式选 legacy_chunks，不将 bounded repair 静默切成更短碎片，也不遗漏文本或绕过模型容量。
生成 MP3/WAV、文字稿、章节、字幕初稿和时间轴。抽查数字、买入/卖出、正负号及语义方向；不要只证明文件存在。

完成标准：实际完整音频可播放；主讲有效发言比例满足要求；与来源一致；配套文件可用于后期。

### 5. 修改或继续

用户说“continue/继续”时，先读已有计划、缓存与运行状态，不能重启并重复生成正常段落。
用户指出铺垫不足、读音问题或个别台词问题时，读 [revisions.md](references/revisions.md)，只重生成受影响的完整 turn。
开头应能自然衔接正文，不能把两句欢迎语生硬粘在旧的突兀开头前。

完成标准：新版本或修订预览可播放；正文正常部分复用；章节/字幕时间更新；清楚指出改了哪一处。

## 交付

先给可播放音频，再给完整稿/章节和字幕。保留绝对本地文件路径，按宿主要求渲染。
不要把图像、动漫小人、视频、自动发布或声线训练加进默认任务。用户另有明确要求时再处理。
不提交本机配置、实际绝对路径、输入资料、原始声音、模型权重、conditioning `.pt`、登录态、输出成片或完整 ASR 私有记录到代码仓库。
