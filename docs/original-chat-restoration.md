# 10 月 2 日闲聊恢复：根因与迁移

## 恢复的不是版本号

目标是两条链路同时恢复：

1. **声音**：铃木爱奈/濑户麻沙美的原始日语演员音色参考，与原始中文聊天片段的 delivery 情绪参考分开；alpha 0.5、原始解码采样和正文参数随配方保留。
2. **写作**：人物与场景铺垫、好奇、轻玩笑、双方有实质贡献；久留美承担主要解释和串联，不退化为干巴巴的轮流念稿或老师/学生问答。

当前 main 的 v0.3.0 恢复工作流以 `original-chat-20261002` 为入口；公开参数/资产身份见[配方](../recipes/original-chat-20261002.json)，本地绑定见[运行文档](../skills/research-podcast-kurumi/references/runtime.md)。v0.2.0 保留为未获认可的独立实验，不把它的换搭档、无外部情绪或连续上下文偏好带回原始模式。

## 已确认的输入失配

| 证据 | 失配及影响 |
|---|---|
| 原始正文脚本配置了两个 JA 音色参考和按角色/delivery 指定的 ZH 情绪库 | 原声音不只依赖演员样本；中文聊天的情绪与韵律是独立输入 |
| v0.1.0 模板的两个 `emotion_audio` 都是空字典 | 模板没有携带真正使用过的情绪库，不能靠 pin 版本补回来 |
| 本次 v010 回退运行保留了 `emo_alpha=0.5`，但两个情绪映射仍为空；该运行 README 记录 native effective alpha 回到 1 | 配置上的 0.5 不证明实际混入了外部中文情绪；无 `emo_audio_prompt` 时 native 改用音色参考并设 alpha=1 |
| 回退仍使用同一个平淡的七轮剧本，并换了搭档 | 版本回退同时没有恢复写法和原始角色；不能把听感问题全部归因于版本 |

上游 [IndexTTS2 论文](https://arxiv.org/html/2506.21619)支持音色与情绪解耦；[已核对的 native 实现](https://github.com/index-tts/index-tts/blob/d9e41aac89fd00b3d71497fddb287b7f24613712/indextts/infer_v2.py)包含无外部情绪时的 alpha=1 回退。`use_random=False` 约束的是情绪选择随机性，**不是 `do_sample=False`**；恢复参数不能据此关闭解码采样。原始本地 2.5 参数与当前上游默认值也不能混用。

这些记录证明原始输入和写作没有随版本回退恢复，不单独证明某一项就是全部听感差异的唯一原因。新文本仍以短试听反馈判断。

## 三种历史产物要分清

- **约 41 秒获认可试听**：原开场前八轮使用逐轮中文情绪参考。历史认可只针对该产物。
- **修订的前 60 秒开场**：后来加了人物/话题铺垫，再与已有正文衔接；不是那段 41 秒试听的另一个文件名。
- **完整正文**：使用角色/delivery 情绪库，正文每轮 seed 为 `20261002 + 900 + turn`，参数见运行文档。恢复入口复用这套正文配方，不声称它逐字复刻前八轮试听的输入。

原始文字稿《完整文字稿与章节_开场修订版》的前 70 行是本次写作取材依据。仓库[唯一短样](../examples/preview.json)保留前两句铺垫和“减震器帮倒忙”的 GEX 讲解，将解释缩成自然短轮；来源说明保留历史白皮书线索，不冒充新研究。它是**新写作/新渲染候选，尚非用户认可的声音**。

## 最短迁移

1. 使用根仓库当前 main，保留[历史标签](https://github.com/jowilksasella/AI_Podcast-Kurumi/tags)作追溯。保留旧配置和旧输出，不覆盖正常母带。
2. 在本地准备八个原始槽位；现有文件可直接绑定，也可一次性按槽位名复制到忽略的本地库。改名不等于恢复身份，绑定检查要通过。原始文件缺失/不匹配时列出槽位，不重新生成替代情绪或重剪样本。
3. 运行 `bind-original --assets DIRECTORY --index-home DIRECTORY --out config.local.json`，由命令生成冻结配置。不从历史模板复制空映射、不套入 v0.2.0 配置。
4. 用同一个冻结配置校验、渲染新短样；实际时长和主讲比例在音频完成后检查。保留情绪库与采样，必要时先缩短台词而不是随意调参。
5. 交付真实音频供试听，记录反馈；新短样明确获认可后才写/渲染全篇。只修失败段落，不重做正常部分。

绑定锁定的是配方、资产身份和参数；它不保证任意新文本逐位相同，也不自动保证声线美感或自然度。文件存在、无削波和 ASR 正确是技术检查，不能取代[听感与分工检查](../skills/research-podcast-kurumi/references/revisions.md#针对性检查)。
