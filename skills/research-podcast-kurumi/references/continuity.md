# 连续语气：最小排查

用于声线校准或用户指出跨句“跳层”；不是常规节目制作之外的一套训练流程。
版本化案例与适用范围见 [continuity-v0.2.0.md](https://github.com/jowilksasella/AI_Podcast-Kurumi/blob/v0.2.0/docs/continuity-v0.2.0.md)。该链接在新 tag 发布后可用；操作步骤保留在本 reference 中，单独安装 Skill 也可读取。

## 步骤与完成标准

1. **定位反馈**：区分音色不符、跨句音高/力度/发声方式重启、读音错误、空白太长。只有空白问题才做边界剪辑；剪 pause 或 fade 不能修复生成 context。完成标准：这次短样只验证一个具体失败。
2. **固定条件**：沿用同一用户确认的平稳原声、同一 text、实际 seed 与 [runtime recipe](runtime.md)，speaker 与默认 emotion 同参考；一次只改变 context 方式。完成标准：本地记录实际条件，未知历史 UI 参数仍标为未知，不猜测位元相同或唯一根因。
3. **检查容量**：一个自然角色短 turn 整段 native 调用；核对当前低显存与 token 拆段路径。超限按 runtime 的失败分支重写自然 exchange，或显式选 legacy_chunks，完整保留意思。完成标准：有实际外部调用方式与内部 segments 证据，不把 one call 自动当 one context。
4. **交付校准**：单独约 5–15 秒即可，记录实际时长，让用户试听；不凑满正式预览时长。ASR 只处理具体文字疑点，SNR、无 clipping 与文件成功不判断音色。完成标准：用户取得可播放的真实短样，音色评价来自人类；没有直接听辨能力时不自称听过。
5. **停止与进入节目**：用户认可且证据足够即交付，保留该参考与 recipe。不要默认重装、换声、全文 ASR 或重训。正式节目另做 30–60 秒样片确认，才进入全篇；校准通过不代表任意 voice/长稿无气声或无跳层。

本次认可短样是在既有 IndexTTS 2.5 上保持完整 turn 的个案，目标是平滑韵律状态，允许正常呼吸、停顿与音高变化。引用案例时注明这是用户试听反馈，不称 ASR 认证。
